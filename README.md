# Day 4 - JavaScript Fundamentals

## Overview

This project contains the exercises and mini-task I worked on for Day 4 of the Frontend Development training.

## Practical Exercises

### 1. Scores

Used an array of 10 scores to calculate the total and average.

### 2. Pass or Fail

Created a function to check if a score is a Pass or Fail.

### 3. Employee Object

Created an employee object with a name, department, role and active status.

### 4. Names and Positions

Used a loop to display names and their positions.

### 5. Even or Odd

Created a function to check if a number is even or odd.

## Mini-Task

### Employee Performance Checker

Created a simple program to check the performance of employees based on their scores.

The program uses:

- Arrays
- Objects
- Loops
- Conditions
- Functions

Performance levels:

- 80-100: Excellent
- 60-79: Good
- 50-59: Average
- Below 50: Needs Improvement
